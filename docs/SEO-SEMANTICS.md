**Проблема со слугами (решена 01.10.2026: страницы — на семейства, `DECISIONS.md`).** Поисковый спрос идёт на «Газель», «Форд Транзит», «Спринтер», «Дукато», а в базе модели разбиты по поколениям («Ford Transit 2000–2014» и «2015+» — две страницы). Решение: либо страницы-семейства (`/modeli/ford-transit` со всеми поколениями), либо в тексте каждой — общий запрос.

**Русские названия семейств (01.10.2026).** Ищут «форд транзит», «газель некст», «спринтер», а семейства в базе названы латиницей. Ссылки и хлебные крошки — без перевода. Новое латинское семейство в совместимости — дописать его русское название туда же.

**1. 292 адреса из индекса и статистики на новом сайте отдали бы 404** (`new-site-404.csv`; проверено правилами `proxy.ts` по таблице переадресаций и слугам dev-базы). **2. Заголовки товаров и категорий сидений менять до переключения рискованно.** Раздел «Сиденья для микроавтобусов» — первая страница сайта по кликам, «Интурист-Люкс» — вторая; диваны, салазки и рельсы — в первой двадцатке. **3. Google — 38% поискового трафика, Search Console нет.** Без неё просадку в Google не увидеть.

**Сделано в тот же день** (`DECISIONS.md`, «Переезд сайта без потери позиций»):

- Правило запасной переадресации `fallbackLocation` (`packages/domain/src/site/redirects.ts`) в `proxy.ts`: путь из нескольких сегментов — на самый глубокий известный сегмент (товар, категория или старый адрес из таблицы), поиск `index.php` — на `/poisk?q=…`, корзина — на `/korzina`, прочие `index.php` — на главную. `product_id`, которого нет в таблице, ищется по номеру OpenCart (`Product.externalId`). Семь одиночных адресов удалённых товаров — строками `UrlRedirect` (миграция `20261001200000_seo_keep_titles_redirects`). Из 292 адресов 404 остаются только мусорные: `wp-login.php` и два `*.htm`.
- Заголовки и описания шести категорий сидений возвращены дословно (та же миграция); тексты под списком товаров оставлены. Заголовки товаров из таблицы Б не применялись.
- `pnpm erp check:site-urls` проверяет, кроме снимка, адреса из индекса (`--indexed=`, по умолчанию `wm-pages-in-search.csv`): только код ответа, без сверки метатегов.
- Через 3–4 недели после переключения: сравнить трафик с замером, затем вернуть новые заголовки категорий (миграция `20261001150000_seat_categories_meta`) и применить отложенные товарные — по одной группе, с замером между ними.
