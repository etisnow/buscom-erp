- Посадочных «категория + модель» (`/modeli/gazel-next/{слуг категории}`) нет — этап 7, решение за владельцем. Ключи таблицы 2 — готовый список приоритета.

**Проблема со слугами (решена 01.10.2026: страницы — на семейства, `DECISIONS.md`).** Поисковый спрос идёт на «Газель», «Форд Транзит», «Спринтер», «Дукато», а в базе модели разбиты по поколениям («Ford Transit 2000–2014» и «2015+» — две страницы). Решение: либо страницы-семейства (`/modeli/ford-transit` со всеми поколениями), либо в тексте каждой — общий запрос.
