## Известные проблемы и долги

- **Миграция не проверена на живой БД.** Сгенерирована через `prisma migrate diff` без Postgres (Docker на машине автора не был установлен). Первый `migrate deploy` может выявить ошибки.
- **Таблицы Better Auth написаны вручную** (`user`, `session`, `account`, `verification`) по документации, а не сгенерированы CLI. При первом входе проверить, что Better Auth с ними работает; при расхождениях сверить с `@better-auth/cli generate`.
- **`.claude/settings.json` запрещает `Read(.env.*)`** — это блокирует и `.env.example`. Заменить на `Read(.env.local)` и `Read(.env.production)` (агенту правка собственных настроек запрещена — делает человек).
- **bus-com.ru не открывается из сессий с VPN** — данные о сайте брать у заказчика, а не скачивать.
- **Git-автор первых коммитов** — рабочий адрес из глобального git-конфига; для этого репозитория, возможно, стоит задать `git config user.email` локально.
