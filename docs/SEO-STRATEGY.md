## Коротко

Стратегия на 12 месяцев: сначала переехать на новый сайт без потери трафика, затем расти за счёт модельного спроса («сиденья для Газель Next», «сиденье Форд Транзит»), которого старый сайт не собирал. Основной поисковик — Яндекс, поэтому вес на коммерческих факторах и Вебмастере; Google — вторым.

Пять ставок, по порядку:

1. **Безопасное переключение.** 699 старых адресов отвечают 200 или 301, ручные метатеги сохранены, первые 4 недели — ежедневный контроль индекса.
2. **Посадочные «семейство × категория».** Уже построено 74 страницы на dev-базе; растут по мере разметки совместимости в ERP.
3. **Тексты и метатеги под спрос.** Шаблоны с «купить», «пассажирские», номерами кузовов (W906, 244/250, Т5) для категорий, моделей и посадочных.
4. **Коммерческие факторы Яндекса.** Цены, доставка по России, реквизиты, отзывы, Яндекс Бизнес и Товары.
5. **Расширение семантики** на остальные разделы (опоры, комплектующие, ремни, стёкла, люки) и ассортимент под крупный спрос, которого нет в каталоге (Вито, Транспортер).

## Структура и посадочные

Индексируем пять типов страниц, каждый под свой кластер запросов; всё остальное (фильтры, сортировка, поиск, корзина) закрыто или склеено canonical.

Схема внутренних ссылок (в живом документе — рисунок):

- Главная → категории (мега-меню) и семейства моделей (подбор по модели).
- Категория (`/sidenja-dlya-microavtobusov`) → посадочные своих моделей → товары; категория → все товары раздела.
- Семейство модели (`/modeli/ford-transit`) → посадочные своих разделов.
- Посадочная (`/modeli/ford-transit/{категория}`) получает ссылки и с категории, и со страницы модели; ведёт на товары подборки.
- Товар (`/{слуг}`, 215 товаров) → совместимые семейства.

Адреса не меняются при переименовании; хлебные крошки ведут по этой же иерархии.

Правила:

- **Посадочная живёт при 3+ товарах.** Ниже порога — вне карты сайта и 301 на страницу семейства (сделано 01.10.2026): иначе при снятии товара с продажи теряем накопленные позиции. Неизвестные семейство или категория — 404.
- **Семейство, а не поколение.** Номера кузовов (W906, 244, Т5) — в тексте, подзаголовках и подсказке «подходит для», отдельных страниц под них не делаем.
- **Фильтры не индексируются.** Фильтр «подходит для модели» в категории, если для пары есть посадочная, ведёт обычной ссылкой на неё — так робот видит посадочную вместо дубля.
- **Пагинация** `?page=N` индексируется с canonical на себя; текст категории — только на первой странице.
- **Перелинковка по схеме выше:** категория → её посадочные (блок «по моделям»), семейство → его разделы, товар → семейства и посадочные своей категории, посадочная → соседние семейства в той же категории. Любая страница — не глубже 3 кликов от главной.
- **Снятый с продажи товар** не отдаёт 404: либо страница остаётся с пометкой «нет в продаже» и аналогами, либо 301 на замену или категорию.

## Техническое SEO

Основа готова; до переключения остаются скорость и коды переадресации на хостинге, после — ускорение индексации и постоянный контроль.

| Задача                                                                                                                     | Зачем                                                      | Когда             |
| -------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- | ----------------- |
| http → https и www → без www отдают 301 одним шагом (сейчас у Джино 302)                                                   | 302 не передаёт вес старого адреса                         | день переключения |
| Мобильный LCP ≤ 2,5 с: картинки в хранилище + CDN, webp/avif, приоритет главному снимку                                    | скорость — фактор ранжирования и конверсии на мобильных    | до переключения   |
| robots.txt: `Clean-param` для utm, yclid, sort; убрать устаревшую директиву `Host`                                         | Яндекс склеивает адреса с метками и не тратит на них обход | сделано 01.10     |
| Из карты сайта убрать `/status-zakaza`, `/privacy`                                                                         | служебные страницы без поискового спроса                   | сделано 01.10     |
| Отвечать на `If-Modified-Since` (304) и отдавать `Last-Modified`                                                           | робот Яндекса быстрее обходит и меньше нагружает сервер    | месяц 1           |

Тексты по приоритету:

1. **Топ-10 посадочных по спросу** (Транзит, Газель Next, Газель Бизнес, Спринтер, Дукато, Соболь…) — ручной текст 600–1 000 знаков: какие поколения и кузова подходят, как крепится, сколько мест в салоне, что нужно для регистрации. Нужно поле текста у посадочной в ERP.
2. **Остальные посадочные** — автоматический абзац из данных: число товаров, вилка цен, поколения, соседние разделы. Достаточно, чтобы страница не выглядела дублем категории.
3. **Карточки товаров** — таблица характеристик (размеры, материал, число мест, тип крепления, ремни), синонимы из семантики (рельсы / салазки / направляющие), фото в салоне конкретной машины.
4. **Статьи** — если владелец вернёт их в объём (сейчас блог вне PRD). Первые темы: как выбрать сиденья для микроавтобуса; рельсы и крепление — какие бывают; переоборудование грузовой Газели в пассажирскую и регистрация изменений. Каждая ссылается на 2–3 посадочные.

Правило для всех текстов: факты и ответы на вопросы покупателя, а не повтор ключей. Текст под списком товаров, не над ним.

## Внешние каналы и ссылки

Ставка — на площадки Яндекса и отраслевые упоминания, без покупки ссылок: для сайта с десятилетней историей риск санкций дороже выигрыша.

1. **Яндекс Бизнес** — карточка компании с сайтом, категориями «автозапчасти» и «тюнинг автобусов», фото, отзывами. Источник отзывов и доверия для всего домена.
2. **Фид товаров для Яндекса** (YML из базы) — бесплатные товарные блоки в поиске и вкладке «Товары», тот же фид пригодится для Директа. Делается один раз, обновляется сам.
3. **Маркетплейсы и Авито** — витрина с ссылкой на сайт в профиле, если владелец там торгует или готов торговать; в выдаче по модельным запросам они занимают часть топа.
4. **Отраслевые упоминания** — форумы и сообщества владельцев Газелей и Транзитов, каталоги переоборудования, клиенты-автопарки и партнёры-ателье (отзыв со ссылкой). Цель — 5–10 живых упоминаний за полгода.
5. **Старые ссылки** — выгрузить из Вебмастера «Внешние ссылки» до переключения и проверить, что каждая целевая страница отвечает 200 или 301: ссылки могут вести на адреса, которых не было в карте сайта.

## Аналитика и отчётность

Связка «запрос → входная страница → заказ в ERP» — наше преимущество: сайт и ERP на одной базе, и доход от SEO можно считать в рублях, а не в визитах.

- **При оформлении заказа** сохранять в заказе источник и входную страницу визита (поиск / реклама / прямой, utm, ClientID Метрики). В ERP — отчёт «заказы и выручка по источникам и типам страниц».
- **Метрика:** цели (корзина, заказ, «купить в 1 клик», заявка, клик по телефону и мессенджерам), электронная коммерция, сегменты по типу входной страницы (`/modeli/*`, категории, товары).
- **Вебмастер:** делегировать права разработчику, включить уведомления о критичных ошибках, завести мониторинг 25 запросов ядра («Мониторинг запросов» бесплатен).
- **Search Console:** подтвердить домен через DNS до переключения — тогда будет база для сравнения по Google.

| Что                                               | Как часто                             | Кому                   |
| ------------------------------------------------- | ------------------------------------- | ---------------------- |
| Индекс, 404 в логах, просадки трафика             | ежедневно 4 недели после переключения | разработчик            |
| Позиции ядра, новые страницы в индексе            | еженедельно                           | разработчик            |
| Трафик, заказы и выручка из поиска, план на месяц | ежемесячно                            | владелец               |
| Пересмотр семантики и целей                       | раз в квартал                         | владелец + разработчик |

## Дорожная карта

Четыре этапа; каждый следующий начинается, когда выполнено условие перехода. Сроки считаются от дня переключения DNS, дата которого ещё не назначена.

1. **До переключения (сейчас)**
   - Совместимость размечена (01.10); CSS отдельным файлом — HTML карточки 54 → 24 КБ
   - Мобильный LCP ≤ 2,5 с: картинки в хранилище и CDN
   - 301 вместо 302 на хостинге (robots.txt с Clean-param — сделано)
   - Search Console; выгрузить ссылки и базу из Метрики
   - Вордстат по остальным разделам каталога

   **Условие перехода — переключение DNS:** 699 старых адресов отвечают 200 или 301, LCP ≤ 2,5 с.

2. **Стабилизация (месяц 1)**
   - Ежедневно: индекс, 404, трафик, заказы
   - IndexNow и ответы 304
   - Яндекс Бизнес, письмо покупателю с просьбой об отзыве
   - Метатеги и адреса старых страниц не трогаем

   **Условие перехода — трафик вернулся:** через 4 недели поисковый трафик не ниже 95% от базы.

3. **Рост посадочных (месяцы 2–3)**
   - Поле текста посадочной в ERP, тексты для топ-10
   - Шаблоны title с русским названием модели
   - Посадочные по остальным разделам по итогам Вордстата
   - YML-фид для Яндекс Товаров; источник визита в заказе

   **Условие перехода — 30+ посадочных:** в индексе Яндекса не меньше 30 посадочных.

4. **Расширение (месяцы 4–12)**
   - Статьи и гайды, если владелец согласует
   - Отзывы и рейтинг на сайте с микроразметкой
   - Ассортимент под спрос без товара (Вито, Транспортер)
   - Упоминания на отраслевых площадках; пересмотр раз в квартал

Работа делится на три руки: разработчик (скорость, разметка, фид, отчёты), менеджеры в ERP (совместимость, характеристики, фото) и владелец (тексты, Яндекс Бизнес, решения по ассортименту).
